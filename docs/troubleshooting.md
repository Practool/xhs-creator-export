# XHS Creator Export：常见问题与故障排查

本页面向安装或采集遇到问题的用户。先保存任务 ID，用 `node dist/cli.js status YOUR_JOB_ID` 查看原因；已生成报告时同时查看 `validation.json`。

## 登录失效或出现验证码

**现象**：窗口显示登录或验证，或无界面任务标为 `waiting_for_user` 并退出。

**可能原因**：登录状态过期，或平台要求交互验证。

**处理步骤**：可见模式在专用窗口自行登录、扫码或验证，程序确认后继续。无界面模式执行 `node dist/cli.js login`，成功后执行 `node dist/cli.js resume YOUR_JOB_ID`。不自动从无界面切换可见窗口；使用自定义配置时，两个命令都要加同一 `--config`。不要分享二维码、Cookie 或账号密码。

## 日期不接受，账号或目录发生变化

**现象**：筛选范围无法核对、目录数量变化、账号不一致，任务停止并保留结果。

**可能原因**：指定日期超出平台范围、账号切换、发布或删除笔记改变了目录。

**处理步骤**：确认日期为有效起止日期且平台允许访问，不要操作正在采集的浏览器。恢复原账号和条件后尝试 `resume`；需要新的日期范围、或原目录无法恢复时，执行 `collect` 创建新批次。不要手工编辑数据库绕过校验。

## 官方导出失败

**现象**：`complete_with_warnings`，或报告提示导出未下载、超时、格式错误。

**可能原因**：平台没有触发下载、网络超时或文件内容未通过验证。

**处理步骤**：查看 `validation.json` 中的笔记和原因，详情及截图可能已保存。必要时执行 `node dist/cli.js retry YOUR_JOB_ID --note YOUR_NOTE_ID`。不带 `--note` 的重试会跳过已完整完成的详情记录，不保证重试其中的官方导出警告。

## 页面结构变化或控件找不到

**现象**：定位、字段识别或截图步骤反复失败。

**可能原因**：平台页面调整、模块结构变化或数据没有加载完成。

**处理步骤**：保存任务及错误信息，更新工具适配后再 `resume`。不要把失败当成数据不足，也不保证升级后一定成功。反馈问题时按[隐私说明](privacy.md)脱敏。

## 登录目录锁或提示已有任务运行

**现象**：程序提示浏览器目录已有任务。

**可能原因**：另一个任务或登录窗口仍在使用同一专用 profile。

**处理步骤**：先确认其他任务已经正常退出。活跃锁不自动删除，**不要删除正在使用的锁文件**；程序可回收确认进程已退出的失效锁。锁损坏时，确认无任务、备份目录，再根据明确提示处理。

## 文件缺失或任务非完整

**现象**：`partial`、完成数不足，或报告提示缺失、损坏文件。

**可能原因**：采集失败、中途停止、文件被移动或输出目录被改动。

**处理步骤**：确认使用原配置、数据库和输出目录，执行 `resume YOUR_JOB_ID` 核对并重采；仍失败时检查原因或用 `retry`。`export` 只重新生成已保存数据的汇总，不下载缺失文件。部分结果可以使用，但不能标为完整结果。

## 没有 Chrome 或 Linux 缺少依赖

**现象**：`doctor` 提示浏览器不可用，或启动时报告缺少共享库。

**可能原因**：Chrome 未安装、Playwright Chromium 未下载、系统库缺失。

**处理步骤**：安装 Chrome，或在安装目录运行 `npx playwright install chromium`。Linux 缺系统依赖时执行 `npx playwright install --with-deps chromium`。完成后重新运行 `doctor`，需要实际启动检查可执行 `doctor --launch`。

## 安装依赖失败或 Node 版本不对

**现象**：CLI 提示需要 Node.js 24，或 npm 报原生模块安装错误。

**可能原因**：终端仍使用另一版本的 Node、依赖下载失败，或需要本机编译。

**处理步骤**：用 `node --version` 确认 `v24.`，检查网络，再依[安装教程](getting-started.md)处理编译工具。不要把特定机器上的运行时绝对路径写进共享配置。

## 升级或重装

**现象**：需要替换程序文件，担心登录态和续采丢失。

**可能原因**：配置、登录 profile、数据库及产物保存在程序旁边，覆盖整个目录会丢失数据。

**处理步骤**：先退出全部任务，备份 `xhs-creator-export.yaml`、整个 `.xhs-creator-export/` 和自定义 `outputDir`，再替换程序文件。使用自定义配置时，也需备份原配置，并继续使用同一配置。详见[配置说明](configuration.md)。
