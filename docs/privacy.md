# XHS Creator Export：隐私与使用说明

本页面向使用、分发程序或反馈问题的用户。请先了解本地保存的数据、浏览器联网行为和公开分享的边界。

## 非官方工具与访问边界

XHS Creator Export 是非官方独立开源工具，与小红书不存在官方授权或关联。仅用于导出用户自己账号在创作服务平台正常可访问的数据，使用者应遵守适用的平台规则与要求。

程序通过正常浏览器交互、相关响应和平台提供的导出按钮采集，不绕过登录、验证码或其他访问限制。可用日期与模块由平台决定；页面变化和访问限制可能导致失败。使用后检查完整性报告，不承诺所有数据持续可用。

## 本地保存的内容

- 专用浏览器 profile 默认在 `.xhs-creator-export/profile`，保存登录状态，可能包含 Cookie、本地存储及其他会话资料。
- `.xhs-creator-export/tasks.sqlite` 保存任务进度，可能包含账号关联、内容及错误信息。
- 导出文件、原始相关响应、截图及 JSON 索引可能包含账号、笔记标题、内容指标和身份关联信息；控制台及个人日志也可能含账号信息。
- `xhs-creator-export.yaml` 保存配置，包括本地目录。使用自定义配置或目录时，保护方式相同。

程序不读取或复制日常 Chrome 个人资料。独立 profile 仍属于敏感登录资料，不能当作普通程序文件分享。

## 联网行为

运行采集浏览器会连接小红书创作服务平台及其页面、资源、验证和下载服务；浏览器和平台页面自身也会产生网络请求。安装 npm 依赖、下载浏览器、访问文档中的外部链接或徽章会连接对应服务。

当前项目源码未实现另设的遥测、远端数据上传或模型 API 功能，采集结果由程序写入本地。此说明不代表浏览器、平台页面或第三方依赖绝不联网，也不构成全面安全审计结论。

## 公开提交与分享

不要把浏览器 profile、Cookie、二维码、会话、个人配置、任务数据库、真实 XLSX/CSV/JSON、ZIP 或包含个人信息的截图提交到公开仓库或安装包。只分发干净的程序安装包，不打包运行后的整个目录。

仓库 `.gitignore` 排除默认状态目录、个人配置及示例 `downloads/`；**自定义输出路径不一定被忽略**，每次提交前仍需检查文件清单。忽略规则不会自动取消已经跟踪的文件。发现敏感文件已被跟踪时，先停止发布，保留本地数据，再单独处理移除跟踪及必要的历史清理。

反馈问题时脱敏终端输出、笔记 ID、标题、账号名、头像、路径及截图。演示图应展示真实行为，不能包含登录二维码或会话信息；当前文档未提供演示截图。

备份与升级步骤见[故障排查](troubleshooting.md)，输出范围见[数据口径](output-files.md)。
