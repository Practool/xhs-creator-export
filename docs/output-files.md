# XHS Creator Export：输出文件与数据口径

本页面向需要查看、分析和备份导出结果的用户。先核对任务状态及完整性报告，再使用 Excel、CSV 或 JSON。

## 目录结构与用途

默认目录为 `.xhs-creator-export/jobs/<任务ID>/`，可在[配置](configuration.md)中指定其他 `outputDir`：

```text
<任务ID>/
  archive.zip
  小红书笔记分析总表.xlsx
  笔记分析总表.csv
  content-data.json
  validation.json
  official/
    note-list.xlsx
    YYYY-MM-DD_HH-mm-ss_笔记标题.xlsx
  core-view-trends/
    hour/YYYY-MM-DD_HH-mm-ss_笔记标题/full.png
    day/YYYY-MM-DD_HH-mm-ss_笔记标题/full.png
  trends/
    YYYY-MM-DD_HH-mm-ss_视频笔记标题/full.png
```

官方表格按实际下载内容检测格式，可能保存为 `.xlsx` 或 `.csv`；上述 `.xlsx` 为常见示例。图文不生成不适用的视频观看趋势截图。

| 输出 | 用途 |
| --- | --- |
| Excel 总表 | 每篇笔记一行，包含指标及产物引用，方便筛选分析 |
| CSV 总表 | 程序处理、导入其他分析工具 |
| `content-data.json` | 结构化数据、相关响应、来源与产物索引；包含格式版本 |
| `validation.json` | 完成数量、产物校验、警告、错误及完整性判断 |
| `official/` | 平台导出按钮生成的列表及逐篇核心数据文件 |
| `core-view-trends/` | 核心观看数按小时、按天各一张完整截图 |
| `trends/` | 视频适用的观看趋势模块截图 |
| `archive.zip` | 汇总文件、报告与已索引产物的备份包，不含登录 profile 或任务 SQLite |

任务 SQLite 位于 `.xhs-creator-export/tasks.sqlite`，用于续采。仅备份 ZIP 不足以保留可续采状态；升级和迁移时备份整个状态目录及配置。

## 命名规则

逐篇官方文件和截图目录采用上海时区的 `YYYY-MM-DD_HH-mm-ss_笔记标题`。非法字符替换、长标题截断，同名加短后缀，截图文件名为 `full.png`。笔记 ID 仍用于内部关联，避免标题相似导致数据混淆。发布时间或标题缺失时会使用未知时间、无标题等回退名称。

`export YOUR_JOB_ID` 会对已有批次重建数据行，并在可验证文件的基础上更新可读命名及引用，不重新下载；请保留整个任务目录。

## 指标与模块

采集核心及互动指标，以及平台提供时适用的诊断数值、同类中位数、超过占比、比较说明和建议、观看来源、观众画像。视频与图文按适用模块处理。

不包含账号概览、粉丝看板、直播或互动趋势时间序列。观看趋势保存截图，不从图片推测数值；暂未加载不能作为不适用的依据。

官方导出失败时，详情和截图可能已保存，报告会单独记录警告。必要数据或截图缺失则不能标为完整。平台数据不足、模块不适用、采集失败分别记录，空值不转为 0。

## 数值规则

- JSON/CSV 百分数 `26.9` 表示 `26.9%`；Excel 使用真实百分比格式。
- 时长单位为秒，未明确映射的诊断保留原值并注明单位未推断。
- 发布时间、数据更新时间、采集时间分别保存；可读时间采用上海时区，Excel 保存时间文本以避免时区漂移。
- CSV 对公式开头文本做保护，Excel 文本以字符串保存。

重新导出从已保存相关响应重建已完成笔记的数据行；不补回采集时没有获取的数据。字段随平台实际模块而变化。

## 判断结果是否完整

`partial` 不是完整下载；数量一致也不能代替产物校验。检查 `status` 和 `validation.json`，核对范围、完成数、缺失、错误及官方导出警告。页面变化或访问限制可能造成失败；处理方式见[故障排查](troubleshooting.md)。

真实数据及截图可能包含身份关联信息，请按[隐私说明](privacy.md)保管，不要直接公开提交。
